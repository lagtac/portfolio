### 1. SharePoint 2013 intranet Portal (KPMG Greece)

- **Years:** 2016–2017
- **Role:** Content Manager; content and front-end lead on the portal migration
- **What I did:** Migrated the firm's SharePoint 2007 intranet portal to
  SharePoint 2013. Defined page layouts and document types, mapped and migrated
  content, wrote the page-type, image-size, and colour reference cards, and
  configured the web parts (Tiles, Spotlight, Advertisement, Event, Image
  viewer). Built a small Python + REST helper (`spapi.py`) against the portal
  API. Coordinated with the global GCK/ITSG migration teams and the section
  owners (Marketing, IT, HR, Risk, BD).
- **Skills:** SharePoint 2013 · content governance · information architecture ·
  metadata/taxonomy · web-part configuration · HTML/CSS · Python + REST ·
  stakeholder coordination
- **Outcome:** Served as the content and front-end lead on the Greece portal
  migration, producing the reference cards and web-part patterns the section
  teams built against.
- **Evidence:** `~/Downloads/kpmg/Projects/Portal/` (`docs/`, `sections/`,
  `scripts/`, `api/`, `migration/`)
- **Confidentiality:** KPMG internal intranet screenshots and global migration
