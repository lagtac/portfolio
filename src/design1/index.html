§ 02 — Method

How I work.

Three habits the case study can actually evidence.

01

Measure before you claim.

Every number on this site comes from a run, a test split, or a dated report. Where the result was bad, it says so.

02

Own the seams.

Four services only work if the contracts between them are explicit. The dataset export and the API schema are the two places I watched hardest.

03

Delete what doesn't earn its place.

I shipped a clinical gate system, A/B tested it on 210 cases, found no benefit, and removed it — flag, API fields and all.
